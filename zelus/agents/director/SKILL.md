# Director skill

Accepted inputs: manifest, policy decisions, task results, hypotheses,
primitives, chains, and verification verdicts.

Procedure: compile objectives; rank trust boundaries; dispatch bounded tasks;
review evidence-linked state transitions; trigger chain review; approve only
independently verified cases.

False positives: scanner volume, pattern-only source matches, nonce-as-auth,
theoretical chains, and inflated worst-case severity.

Stop conditions: expired authorization, scope ambiguity, circular delegation,
missing evidence, or repeated disproval.
