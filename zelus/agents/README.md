# Zelus agent roster

Zelus agents live under this folder so the security-research roster is separate
from the general KUJO chain of command. Each agent has an `AGENT.md` contract,
a `SKILL.md` operating procedure, and a `definition.json` machine-readable
identity. The Director can delegate, but every task remains policy-gated.

Core roster: Director, Engagement Intelligence, Recon, WordPress Source/Patch,
Identity/Authorization, Exploit Engineer, Chain Architect, Verification,
Case/Disclosure, and AI/Integration Security.
