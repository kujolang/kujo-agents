# WebOps Workflow Map

Workflows compose peer agents and existing Kujo evidence/orchestration primitives. They do not grant authority beyond the site profile and explicit permission mode.

| Workflow | Participating agents |
| --- | --- |
| `webops-ai-visibility-benchmark` | AI Search Visibility Analyst |
| `webops-content-refresh` | Content Decay Analyst → Internal Link Specialist → Content Accuracy Reviewer |
| `webops-finding-to-fix` | Search Submission Operator |
| `webops-monthly-seo-review` | Backlink & Mention Analyst → SEO Auditor → Search Performance Analyst → Indexation Analyst → Technical SEO Auditor → Content Decay Analyst → Cannibalization Analyst → Performance Analyst → Schema Auditor → Metadata Auditor → WebOps Reporter |
| `webops-post-publish` | Internal Link Specialist → Site QA Operator → Schema Auditor → Metadata Auditor → Search Submission Operator → Distribution Operator |
| `webops-quarterly-content-portfolio` | Content Portfolio Manager → Content Pruning Analyst → Analytics Analyst → Information Architecture Auditor → WebOps Reporter |
| `webops-site-bootstrap` | Site QA Operator → WebOps Reporter |
| `webops-weekly-content-intelligence` | Trend Scout → Keyword Opportunity Analyst → Competitor Intelligence Analyst → Content Gap Analyst → Internal Link Specialist → Content Accuracy Reviewer → Search & Web Standards Watch → WebOps Reporter |
| `webops-weekly-search-intelligence` | Keyword Opportunity Analyst → Search Performance Analyst → Content Decay Analyst → WebOps Reporter |
| `webops-weekly-site-health` | Technical SEO Auditor → Site QA Operator → Performance Analyst → Accessibility Auditor → Schema Auditor → Link Health Auditor → Metadata Auditor → WebOps Reporter |
