# Shared production media service

These production tools are owned by `kujo-agents/videoops/tools`. They support the five creative roles, HyperFrames, and the harness-driven `videoops-production` route. The retired standalone repository is not required. Legacy job orchestration and fixture runners are not part of this tool package.

## Implemented capabilities and boundaries

| Provider | Capability | Execution | Verification |
| --- | --- | --- | --- |
| ElevenLabs | Speech with optional/required character timestamps | Synchronous HTTP POST | Live Free-plan smoke PASS, 2026-09-07 UTC; timestamps and deterministic audio QA verified |
| ElevenLabs | Sound effects | Synchronous HTTP POST | Mocked binary response; live saved-key request rejected as unauthorized |
| ElevenLabs | Music | Synchronous HTTP POST, capability-specific entitlement required | Mocked binary response; Free-plan preflight blocked, no live generation |
| Local | Existing audio/video import | No network; original bytes preserved | Real local CLI/workflow test |
| Any | Transcription, separate alignment, catalog, asynchronous jobs | Explicitly unsupported in this version | No capability claim |

The adapter supports MP3/WAV provider output. Local import accepts ordinary WAV, MP3, MP4/MOV, Matroska/WebM, Ogg, FLAC and AAC media with positive duration. It rejects playlists, network demuxers, raw PCM without a decoding contract, malformed streams, and unsupported settings. Character alignment uses seconds relative to the start of preserved original media; it does not certify pronunciation or edit timing. Media generation requests specify a model and (for speech) voice; availability is checked by the actual API response rather than an outdated hard-coded catalog.

Current synchronous endpoints expose neither a cancellable asynchronous job nor a documented idempotency contract used here. The adapter does not invent polling/cancellation endpoints, forward credentials to download URLs, follow redirects, inherit proxies, silently substitute providers, or retry ambiguous calls. Runtime currently requires a POSIX host (macOS/Linux file locks), Python >=3.10, jsonschema, ffmpeg and ffprobe. Portable artifacts can be consumed by other harnesses; a Windows execution port is not claimed.

## Commands and artifact flow

Run from the `kujo-agents/videoops/tools` directory, or install the package with `python3 -m pip install .` in an appropriate environment. Packaged schema copies are generated by `scripts/sync_package_schemas.py`, checked with `--check`. All request/authorization JSON files and referenced evidence must be inside the selected existing production workspace.

```sh
python3 -m videoops.cli media doctor --workspace /absolute/production
python3 -m videoops.cli media providers --workspace /absolute/production
python3 -m videoops.cli media fingerprint --workspace /absolute/production --request /absolute/production/requests/narration.json
python3 -m videoops.cli media doctor --workspace /absolute/production --request /absolute/production/requests/narration.json
python3 -m videoops.cli media authorize --workspace /absolute/production --authorization /absolute/production/authorization.json --authorize-local
python3 -m videoops.cli media generate --workspace /absolute/production --request /absolute/production/requests/narration.json
python3 -m videoops.cli media status --workspace /absolute/production --request-id narration-001
python3 -m videoops.cli media import --workspace /absolute/production --request /absolute/production/requests/local-audio.json
```

A Scout-produced `assets/asset-manifest.json` must already contain the exact asset ID and requirement ID. Generation requires status `GENERATE`. Import is bounded local acquisition and does not need generation authority. Successful execution creates:

- `media/<request_id>/original.media`: exact provider/import bytes, never overwritten.
- `normalized.wav`: generated audio derivative, preserving rate/channels and originals.
- `alignment.json`: validated character timestamps if returned.
- `result.json`: versioned provenance receipt, fingerprints, hashes, actual stream metadata and observed/reserved usage.
- `handoff.json`: exact result hash and next harness role.

The service adds manifest `media_result` and `acquisition_status`; it preserves requirement `status` and `usage_status`. Resolved acquisition does not establish rights approval. The Editor checks usage approval, consumes the receipt/derivative through HyperFrames media-use/audio placement, and owns mixing and declared derived edits. No cached HyperFrames skill is patched. The native `kujo-workflows/videoops-media-generation/bin/run --media --operation generate|import --workspace ... --request ... --runtime-root ...` bridge invokes this same service; it does not start creative orchestration.

## Contracts and migration

Canonical v1 JSON Schemas live in `kujo-agents/videoops/tools/contracts/media-{request,result,authorization}.schema.json`; `scripts/build_media_contracts.py` is their deterministic source (`--check` detects drift). Review uses `contracts/review-decision.schema.json`. Packaged schemas are generated by `scripts/sync_package_schemas.py`. Portable copies in `kujo-agents/schemas/videoops/runtime` are synchronized by that repository's native schema sync script with a SHA manifest. Do not edit generated copies manually.

These are new explicit v1 media contracts, not a reinterpretation of the legacy fixture manifest or approval. Unknown versions and unknown fields fail. Existing fixture workspaces continue unchanged. To adopt an existing production, add new request artifacts, hashed local rights/entitlement evidence and optional manifest result/acquisition fields; retain legacy requirement and usage fields. The fixture `approval.json` is not accepted by production review. No destructive workspace migration or fixture reset is part of adoption.

Requests bind job/asset/requirement/shot IDs, exact input hash, language, model/voice/settings, target duration, format, alignment intent, rights and attempt lineage. Fingerprints exclude only request ID, attempt/retry lineage, authorization ID and the separately operator-bound budget. Results distinguish `SUCCESS`, `BLOCKED`, `UNSUPPORTED`, `FAILED`, `CANCELLED`, `UNKNOWN_OUTCOME`; missing usage is null, never fabricated zero. Provider headers can report credits; cost remains unknown unless actually observed. Reserved limits are separate. `verification` is local, mock or live; a live HTTP outcome is not a perceptual review or a claim that the provider's entire capability is generally available.

## Credentials, entitlement and authority

Operator authority is a local CLI boundary (`--authorize-local`), not authentication inferred from an artifact. Do not let an untrusted stage grant itself scope. The workspace is controlled by the local operator; these tools do not defend against a malicious same-user process rewriting SQLite or authorization evidence. Existing job API bearer tokens are not silently reused for the media CLI.

Authorization is immutable by ID and persists in a private local SQLite ledger. It binds workspace, provider, capabilities, models, optional voices, output formats, call/credit/currency limits, expiry, credential reference, capability-specific entitlement evidence, and exact `request_bounds` (fingerprint, maximum credits/cost, hashed evidence). The operator approves each request bound before dispatch; requests cannot reduce their own reservation. A bound is a reviewed upper-limit attestation, not a live price oracle. Unknown/unbounded prices, unknown allowance, expired evidence or missing no-overage assurance block execution. Grant new scope if an intended request changes.

Credentials are resolved only at explicitly authorized dispatch/inspection. Use an injected environment reference such as `{"kind":"env","name":"ELEVENLABS_API_KEY","account":null}`, or configure your own `keychain` service/account (macOS) or `secret-service` label/account (Linux secret-tool). No personal service/account is a default. Never put a secret value in an argument or artifact. Provider errors are normalized codes, and response logs preserve only an allowlist rather than raw messages. Automated tests use dummy values and never access a private account. The separately authorized live smoke used a saved credential reference; its audio and private inspection receipts are excluded from this repository.

Offline doctor never resolves secrets or contacts an account. Optional `--request` evaluates local scope/evidence and dependencies; authentication remains not checked. Stored result evidence is reported separately. `media inspect --workspace ... --authorization-id ... --authorize-local` explicitly performs a subscription GET, consumes one authorized external call and records a redacted inspection. Its bounded plan tier (or null), remaining credits and no-overage information do not prove music entitlement. Do not infer music access from TTS success or infer promotional rights from an open-source project. Capability-specific rights and entitlement evidence must be current for the intended use.

Concurrent dispatch reserves calls/credits/cost atomically. Failed preflight does not count as a dispatched call. Actual observed credits reconcile the reservation; absent observations retain the conservative reservation. No refund is inferred from failure/cancellation, and no upgrade or overage action exists. Revocation stops future dispatch; it cannot recall a provider call already started.

## Retry and cancellation

Reusing a request ID returns its recorded outcome, never sends again. Changing its content raises a conflict. A new ID with the same fingerprint is blocked unless it names the immediately previous explicitly reconciled attempt and increments its attempt number. A per-request process lock prevents disposition while a dispatch is still active. A crashed process releases that lock, allowing the operator to reconcile the persisted uncertain dispatch after checking its external outcome.

```sh
python3 -m videoops.cli media reconcile --workspace /absolute/production --request-id narration-001 --disposition confirmed-failed --authorize-local
python3 -m videoops.cli media revoke --workspace /absolute/production --authorization-id bounded-session --authorize-local
```

`confirmed-cancelled` records a local operator disposition; it does not claim remote cancellation or a refund. Reconciliation does not itself generate a retry. Timeouts, uncertain transport failures and server errors retain an unknown outcome, reservation and original lineage. Do not use local fingerprints as a claim of provider idempotency.

## QA, review and verification

See [source-aware audio QA](audio-qa.md). Its deterministic metrics, heuristic findings and listening requirements are separate. Production review submits an exact candidate, imports an explicit human/agent decision with actual capabilities/evidence, resumes without rerendering, and promotes only the current approved hash. Missing listening/playback review yields `REVIEW_INCOMPLETE`, not an editor repair. Failed renders, user revisions, technical repairs, critic failures and review attempts are separate counters. Fixed paths and style choices from an earlier Kujo film are not defaults.

Meaningful tests are in `tests/test_media.py`, `tests/test_audio_qa.py`, and `tests/test_review.py`; required `bash tests/run.sh` runs the retained production-tool regressions. Official endpoint references checked during implementation: [speech/timestamps](https://elevenlabs.io/docs/api-reference/text-to-speech/convert-with-timestamps), [sound effects](https://elevenlabs.io/docs/api-reference/text-to-sound-effects/convert), [music](https://elevenlabs.io/docs/api-reference/music/compose), [subscription inspection](https://elevenlabs.io/docs/api-reference/user/subscription/get). Historical source verification before migration: the original implementation used mocks. The subsequent 0.3.0 release smoke was explicitly authorized: three subscription GETs, one successful speech POST (53 observed credits), and one unauthorized Sound Effects POST. Music was rejected locally by the Free-plan entitlement gate. No upgrade, audio publication or cloud rendering occurred. See the [sanitized receipt](evidence/elevenlabs-smoke-v0.3.0.json). Missing cost remains null; the account credit delta is not an invoice. The retained SFX reservation is conservative and does not assert a charge.

### Review counter binding through CLI

When the harness explicitly logs `review render-attempt --attempt-id render-1 --outcome succeeded`, pass the same `--render-attempt-id render-1` to `review submit-candidate --candidate output/candidate.mp4` to avoid double counting. Both accept `--user-revision` and `--repair-kind technical|perceptual`. Candidate submission also accepts `--mandatory-capabilities visual_playback audio_listening` and `--max-defect-cycles 3`; preserve the production's configured requirements rather than weakening them to obtain approval. Record failed attempts too. `review record --decision ... --authorize-local` and `review promote --authorize-local` are explicit operator actions, not automatic Editor powers.


### ElevenLabs setup for a bounded live smoke

Create an API key in ElevenLabs with access to the endpoints you intend to test: subscription inspection, text-to-speech, and Sound Effects if needed. Store it in an environment variable or a supported secret store, then reference the secret by name in the authorization. Never paste the key into request JSON, shell history, commits, or logs.

Use offline doctor first. Prepare a Scout manifest, request, hashed rights/pricing/entitlement evidence, and an explicit authorization bound to the computed fingerprint. Free-plan TTS does not grant commercial rights or Music API access. Confirm the current included allowance and no-overage setting; scope the smoke to a short script and a fixed credit/cost ceiling. The subscription GET itself requires inspection authority and counts as a call.

If an endpoint returns `HTTP_UNAUTHORIZED`, check the key's endpoint permissions and account entitlement with the operator. Do not automatically retry or upgrade. After the cause is resolved, reconcile the previous outcome and grant a bounded retry using the next attempt number and `retry_of`. A successful TTS call does not establish SFX access. For audio QA, adapt provider character timestamps into nonempty text segments; whitespace characters are separators, not standalone QA segments. Preserve the complete original alignment artifact.
